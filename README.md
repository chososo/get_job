# Quant Career Desk

퀀트·자산운용·ETF·금융리스크·파생상품평가의 인턴/신입 공고, 지원 캘린더, 경험과 지원서를 관리하는 개인 웹앱입니다.

- 저장소: https://github.com/chososo/get_job
- 배포 예정 주소: https://chososo.github.io/get_job/ (Pages 활성화와 배포 성공 이후 사용)
- 전체 개발 지침: [PROJECT_GUIDE.md](PROJECT_GUIDE.md)
- 일일 작업 지침: [docs/DAILY_ROUTINE.md](docs/DAILY_ROUTINE.md)

## 개인정보 보관

공개 웹앱과 채용 사실 정보만 GitHub에 올립니다. 경험·지원서·별표·개인 일정은 **사용 중인 브라우저의 IndexedDB에 암호화**하여 저장합니다. 비밀번호와 복호화 키는 잠금 해제 세션의 메모리에만 있습니다.

처음 사용할 때 10자 이상의 비밀번호로 보관함을 만드세요. 비밀번호를 잊으면 복구할 수 없습니다. 설정의 **암호화 백업 다운로드**로 별도의 로컬 폴더에 백업하세요. 브라우저 데이터 삭제, 다른 기기/브라우저 사용, Pages에서 로컬 화면으로 이동할 때는 백업 복원이 필요합니다.

로컬 저장은 브라우저 출처 단위입니다. 같은 `chososo.github.io`에 있는 다른 앱과 완전한 보안 격리를 보장하지 않습니다. 별도 도메인 또는 로컬 전용 실행으로 격리를 강화할 수 있습니다. 브라우저와 기기를 타인에게 열어주거나 잠금 해제된 페이지에서 악성 코드를 실행하면 암호화만으로 보호할 수 없습니다.

## 사용 방법

1. 국내/해외 공고에서 분야와 상태를 선택합니다. `지원 가능`은 접수기간과 주니어 표기를 확인한 후보이며 학위·세부 자격은 원문에서 최종 확인하세요.
2. 별표를 누르면 보관함을 열고 중요 공고에 저장합니다.
3. 공고의 `작성 일정 잡기`로 초안·검토·제출 일정을 추가합니다. 공고 원문 마감일과 개인 작성 일정은 별도로 표시합니다.
4. 경험 보관함에 상황·과제·행동·성과를 입력합니다.
5. 작성 도우미에서 회사/직무/문항을 입력하고 경험을 선택합니다. 초안 구조를 만들거나 GPT 요청문을 복사할 수 있습니다.
6. `로컬에 저장`을 누르면 내 지원서에 회사·직무별로 보관됩니다.

## 로컬 실행

Python 3.11 이상이 필요합니다. 웹앱과 GPT 도우미 실행 자체는 Python 기본 라이브러리만 사용합니다.

```sh
cd quant-career-desk
python3 scripts/local_server.py
```

브라우저에서 http://127.0.0.1:8765/ 를 엽니다. 다른 컴퓨터에서는 프로젝트 폴더로 이동한 뒤 같은 실행 명령을 사용하세요. 서버는 127.0.0.1에만 열립니다.

## GPT 연결

API 없이도 `GPT 요청문 복사` → ChatGPT에 붙여넣기 → 결과를 편집기에 붙여넣기 → 로컬 저장 순서로 사용할 수 있습니다. ChatGPT에 붙여넣는 내용은 ChatGPT로 전송되므로 입력 전에 확인하세요.

API 사용 시 별도 OpenAI API 키와 이용 요금이 필요합니다. 키를 GitHub, 소스코드 또는 이 대화에 붙이지 마세요.

```sh
python3 scripts/local_server.py --configure
```

터미널에서 키를 입력하면 화면에는 표시되지 않으며 `.local/openai.json`에 소유자 읽기/쓰기 권한으로 저장됩니다. `.local/`은 Git과 Pages에서 제외됩니다. 모델은 설정에서 입력하며 기본값은 `gpt-5.4-mini`입니다. `OPENAI_API_KEY`, `OPENAI_MODEL` 환경변수도 지원합니다.

로컬 화면의 `GPT로 작성·다듬기`를 누르면 전송할 텍스트를 먼저 보여줍니다. `확인한 내용 전송`을 눌러야 OpenAI API를 호출합니다. 브라우저는 API 키를 받지 않으며, 로컬 서버가 HTTPS로 OpenAI에 연결합니다. 요청/결과를 서버 파일이나 로그에 저장하지 않습니다.

**저장과 외부 처리는 다릅니다.** 개인 문서는 앱/GitHub 서버에 저장하지 않지만 GPT에 보내기로 선택한 내용은 OpenAI가 처리합니다. Responses API에 `store:false`를 지정합니다. 이는 API의 모든 보존이 없다는 보장이 아니며 OpenAI 정책에 따라 abuse monitoring 기록 등이 남을 수 있습니다. 완전한 외부 전송 금지를 원하면 GPT 기능을 사용하지 말고 로컬 초안 구성/직접 편집만 이용하세요. [공식 데이터 정책](https://developers.openai.com/api/docs/guides/your-data)

공개 Pages에서 GPT API 키를 입력받거나 호출하지 않습니다. API 연결은 로컬 화면에서 사용하세요. Pages 자료를 옮길 때는 암호화 백업/복원을 이용합니다.

## 공고 수집

```sh
python3 -m pip install -r requirements.txt
python3 scripts/collect.py --pages 3
```

최초 수집 시 기준 날짜는 실행 시각입니다. 금투협 관련 키워드 상세 공고, WorldQuant/Jane Street의 공개 Greenhouse API를 수집합니다. 나머지 소스는 상태 페이지에 `별도 확인 필요`로 표시하며 Codex 예약 작업의 웹 탐색으로 보완합니다.

완전 수집을 주장하지 않습니다. 로그인 카페, 동적 사이트, 접근 차단, 어댑터 미연결, 페이지 상한은 수집 현황에 표시합니다. 날짜·언어·주니어 자격이 불확실한 후보는 `조건 확인 필요`이며, 마감 시각을 추측해 확정하지 않습니다. 웹앱의 새로고침은 저장된 JSON을 다시 읽으며 직접 크롤링하지 않습니다.

소스 설정은 `sources.json`, 공개 출력은 `web/data/jobs.json`, 최근 결과는 `web/data/latest-run.json`입니다. 기존 기록은 수집 실패로 삭제하지 않습니다. 첫 발견 시 이미 마감한 과거 공고는 기본 수집 목록에서 제외합니다.

웹 탐색으로 검증한 공고는 `scripts/import_jobs.py`의 허용된 공개 스키마로 추가합니다. 연락처, 이력서, 세션 쿠키, 사용자 메모를 입력하지 마세요.

GitHub Pages 자체는 정적 호스팅이라 백그라운드 크롤링이나 닫힌 브라우저의 정시 알림을 실행하지 못합니다. 저장소에는 **배포** 워크플로만 있으며, 수집 예약 워크플로가 있다고 오해하지 마세요.

## GitHub Pages 배포

저장소 Settings → Pages → Build and deployment → Source를 **GitHub Actions**로 지정합니다. `main`에 공개 웹 파일을 올리면 `Publish Career Desk`가 `web/` 중 허용된 파일만 빌드·배포합니다.

```sh
python3 scripts/build.py
```

`dist/`에 실제 공개 산출물이 생성됩니다. 개인 백업, `.local/`, `.env`, 테스트 결과는 포함하지 않습니다. 기존 사용자 파일을 공개하기 위해 상위 폴더에서 `git add .`를 실행하지 마세요.

## 검증

```sh
python3 -m unittest discover -s tests -p 'test_*.py'
node --test tests/domain.test.mjs
node --check web/app.js
python3 scripts/build.py
```

현재 테스트는 마감일·시차·신입/언어 분류·변경 감지·수집 실패 시 보존·암호화·변조 거부·공개 도구 계약을 다룹니다. GPT 유료 호출은 API 키 입력 전에는 검증하지 않습니다. 실제 브라우저 상호작용 QA와 실제 WebMCP 지원 브라우저 검증 여부는 인수인계 기록에 구분해 남깁니다.

## 알려진 한계와 다음 작업

- 모든 사이트의 자동 어댑터가 구현된 상태는 아닙니다. 특히 네이버 카페는 로그인/권한과 여러 게시판 구성을 확인해야 합니다.
- 분류는 보수적인 규칙 기반입니다. 혼합 직무 공고·첨부 문서·학위/언어 복합조건은 사람 또는 Codex의 원문 검토가 필요합니다.
- 원문 ID가 다른 교차 사이트 공고는 자동 병합하지 않습니다. 공식 지원 URL이 같은 후보부터 검증해 병합하는 기능을 확장할 수 있습니다.
- 개인 자료 자동 동기화, Google/Apple Calendar 연동, 클라우드 알림 서비스는 포함하지 않습니다.
- PDF/DOCX 서식 편집은 아직 없으며 텍스트 기반 자소서/CV 관리와 다운로드를 제공합니다.
