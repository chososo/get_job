# 주니어 공고 심사 수정 · 2026-09-08

## 상호 검토에서 확인한 결함

1. `경력 3~5년`, 숫자가 없는 경력직, Senior Assistant가 제외되지 않았다.
2. 다른 자격의 ‘우대’가 필수 경력을 취소했다. 번호가 붙거나 복합적인 자격요건 제목도 놓쳤다.
3. 신입·경력 통합 채용에서 신입 직무와 희망 직무의 연결을 검증하지 않았다.
4. AI 제외 판정이 후속 조건에서 확인 필요로 되돌아갔다.
5. 원문 재수집에 실패하면 구버전 추천 판정이 남았다.
6. NICE평가정보의 통합 공고는 일반적인 채용 제목이어서 초기 직무 필터에서 빠졌다.
7. JSON-LD 본문에 페이지 전체를 덧붙여 다른 공고·회사 소개 문구가 섞였다.

## 수정

- 필수 경력 표현 및 명시적인 경력 전용·상위 직급을 제외한다. ‘우대’는 해당 조건과 섹션에만 적용한다.
- 혼합 채용의 주니어 단락에서 해당 직무의 관련성을 확인한다. 분리 근거가 없으면 추천하지 않는다.
- AI의 제외·필수 현지어·경력 전용 판정을 최종 단계에서도 유지한다.
- 재수집되지 않은 추천은 재검증 대기로 내리되 ID, 별표 연결 및 실제 원문 확인 시각을 보존한다.
- NICE 공식 Greeting 데이터에서 직무별 본문·경력 조건을 분리한다. 같은 공고의 직무도 고유 ID를 갖는다.
- NICE평가정보 공식 공고 234543을 지속 확인 목록에 등록했다. 기획/IR, 데이터 애널리스트, 두 평가모형 컨설팅은 경력 무관이다. 금융데이터 분석·서비스운영은 경력 3년 이상이므로 제외한다.
- 공식 마감 UTC를 한국 시간으로 변환한다. 해당 NICE 공고 마감은 2026-09-21 23:59:59 KST이다.
- 공고 본문과 회사 소개·우대 항목을 구분한다. 소속 컨설턴트의 ‘10~20년 경력’을 지원자 필수 경력으로 판정하지 않는다.
- 별도 확인 목록에 있는 마감·제외 공고도 이력을 보존한다. 일반 검색으로 발견한 신규 부적합 공고는 추천 목록에 추가하지 않는다.
- 원티드의 국가명 `한국`을 `KR`로 정규화해 최초 지정 URL(221698)이 누락되지 않게 했다. 해당 공고는 현재 마감 상태로 보존한다.
- 자격 요약에서 지원자격과 우대사항(필수 아님)을 구분해 표시한다.
- 로컬 새로고침은 매번 새 수집 프로세스를 실행한다. 도우미를 오래 켜두어도 이전 심사 모듈을 재사용하지 않는다.
- 슈퍼루키 검색 경로를 `/jobs/search?q=`로 수정했다.

## 검증

Python 회귀·추출·수집·로컬 서버·공개 파일 제한 테스트와 JavaScript 도메인·로컬 자료 테스트를 실행한다. 경력 범위, 병렬 우대, 번호·복합 자격 제목, 혼합 직무, AI 제외 우선순위, 구버전 이력, 직무별 ID, NICE 시간대 변환을 포함한다.

새로고침과 예약 루틴은 모두 `scripts/refresh_jobs.py`를 사용하므로 같은 수정 규칙을 적용한다. 이번 실수집은 저장된 API 키가 없어 규칙 모드로 수행한다. 접근 실패와 페이지 상한은 수집 현황에 남기며 ‘모든 공고 수집 완료’라고 표시하지 않는다. 원문 스냅샷은 공개 공고만 `.collection-cache/`에 기록하며 배포 파일에 포함하지 않는다.

최종 표시 요약 및 국가명 수정은 이번 실행에서 읽은 공개 원문 스냅샷에 다시 적용한다. 재심사만으로 마지막 원문 확인 시각을 갱신하지 않는다.
