# 모집 직위·필수 경력·삼성 금융권 공고 재검토

## 확인한 문제와 수정

- IBK투자증권 42073은 이미 제외 상태였지만 제외 근거가 포괄적이었다. 이제 본문에서 모집 직위 ‘부장 이상’과 ‘관련 업무 10년 이상’을 별도 추출해 표시하고, AI 포함 판정보다 우선한다.
- 삼성바이오로직스 재무 신입의 입사 후 1년간 공정 경험을 입사 전 필수 경력으로 잘못 판정했다. 입사 후 교육·연수·직무순환과 과거 필수 업무 경력을 구분하여 복구했다.
- 동일 규칙으로 검증한 공고를 일시적인 원문 수집 실패만으로 확인 대기로 내리던 문제를 수정했다. 이전 확인 시각을 유지한다. 규칙 변경 시 저장 원문을 다시 심사하고, 웹에서는 기존의 3일 재확인 기준을 계속 적용한다.
- 삼성 통합 공고의 직무 일부를 놓치던 문제를 수정했다. 공식 회사별 현재 공고 카드와 상세 API의 실제 모집 직무·공통 지원자격·직무별 지원자격을 사용한다. 일반적인 회사 직무 소개는 현재 채용으로 세지 않는다.
- 삼성증권 운용·리서치, 삼성생명 상품계리·자산운용·투자자산관리, 삼성화재 상품개발·계리를 확인했다. 삼성디스플레이와 삼성물산 패션의 재무도 공식 자격요건을 확인해 복구했다.
- 삼성자산운용은 이번 공식 목록에서 현재 공고를 확인하지 못했다. 이를 모집 중으로 꾸미지 않고 공식 목록 확인 대상에 유지한다.
- 기존 공고의 ID를 유지하여 별표와 작성 이력 연결을 보존한다. 동일 ID가 플랫폼과 공식 원문 양쪽에서 들어오면 공식 결과를 우선한다.
- 화면에 모집 직위·필수 경력 항목과 ‘지원 대상 제외’ 필터를 추가했다. 보관된 전체에 제외 공고가 포함된다는 점을 명시하고 제외 카드에는 제외 근거를 우선 표시한다.

## 적용되는 AI 지침

실제 API 호출은 `docs/SCREENING_POLICY.md`를 읽는다. 모집 직위, 최소 경력, 필수와 우대, 신입과 경력 혼합 채용, 언어·학위, 마감, 근거 인용의 순서로 심사한다. 이번 원문 재검토는 규칙 모드로 수행했으며 유료 AI 호출 결과라고 주장하지 않는다.

## 검증 범위

기존 금융권·삼성 등 공개 원문 27건을 다시 읽고, 저장된 전체 공고의 원문 스냅샷을 변경된 규칙으로 재검토했다. 삼성 금융 5개 회사와 재무 2개 회사의 공식 목록을 확인했다. 원문을 다시 읽지 않은 기록의 마지막 원문 확인 시각은 갱신하지 않았다. 테스트에는 IBK의 실제 조건, 삼성 3급 신입과 입사 후 교육, 일시 수집 실패, 저장 원문 재심사, 통합 채용 직무별 경력 검사를 포함한다.
